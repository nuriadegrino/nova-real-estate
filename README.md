# NOVA — Boutique Real Estate V2

Demo de portfolio para una inmobiliaria boutique.

## Novedades V2
- Menú con Favoritos y contador.
- Favoritos persistentes con localStorage.
- 10 propiedades ficticias.
- Tipologías: piso, ático, apartamento, chalet, adosado y villa.
- Filtros por operación, ubicación, precio y tipo.
- Ficha de propiedad completa.
- Galería de 3 imágenes por inmueble con navegación.
- Superficie, habitaciones, baños, extras y características.
- CTA de solicitar visita y ficha completa.
- Diseño responsive.

Los datos y propiedades son ficticios.

Las fotografías del prototipo se cargan desde URLs públicas de Unsplash. Para un proyecto comercial conviene sustituirlas por fotografías propias/licenciadas y descargar/optimizar los assets localmente.

## Siguiente fase comercial
Conectar inventario real/CMS o CRM, formularios de leads, calendario de visitas, WhatsApp, analítica y dominio.
